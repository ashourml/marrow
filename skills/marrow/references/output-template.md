## 11 · Marrow Check — Run Before Shipping Any Component

Do not skip this. These 5 questions are the difference between a component that looks right and one that feels right.

1. **Weight check:** Is my brand accent covering roughly [XX]% of this component's visual area? If it's more — I'm over-expressing. Pull back.
2. **Silence check:** Have I let the layout breathe? Does the canvas-to-content ratio feel like [XX]% canvas? If everything is filled — I've forgotten that space is structure.
3. **Voice check:** Would this user describe this component with the words **[Word] · [Word] · [Word]**? If not — something is off-brand and I need to find it.
4. **Anti-pattern check:** Am I doing any of the 8 prohibited things from Section 8? Check each one explicitly. Don't assume.
5. **Removal check:** If I removed the brand accent entirely, does this component still feel like it belongs to this system? If the answer is no — the soul lives in the accent, not in the design. Start over.
